# Data sources and attribution

All three original datasets are distributed by UCI under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Derived tables and charts in this project transform and aggregate them. The download manifest records source URLs and SHA-256 hashes.

| Dataset | Attribution | Scope |
|---|---|---|
| [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail) | Chen, D. (2015), DOI: 10.24432/C5BW33 | UK online retailer, December 2010 to December 2011 |
| [Bike Sharing](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset) | Fanaee-T, H. (2013), DOI: 10.24432/C5W894 | Capital Bikeshare hourly observations, 2011–2012 |
| [Appliances Energy Prediction](https://archive.ics.uci.edu/dataset/374/appliances-energy-prediction) | Candanedo, L. (2017), DOI: 10.24432/C5VC8G | One dwelling, 10-minute observations over part of 2016 |

These historical datasets support portfolio case studies, not current market claims.
The API integration follows the [official Responses API text generation guide](https://developers.openai.com/api/docs/guides/text).
